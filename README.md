# Computer-Vision
This repository contains all my projects on computer vision.

## Project Modules

### 0. Module Introduction CV
- **Goal**: Introduction to Computer Vision.
- **Key Concepts**: Building a CNN from scratch for multi-label classification, using pre-trained models like VGG16, and fine-tuning.

### 1. Classification
- **Goal**: Medical imaging classification.
- **Specifics**: Brain tumor classification from MRI images into four categories: Glioma, Meningioma, No Tumor, and Pituitary Tumor.

### 2. Hands Gestures Detection
- **Goal**: Real-time hand gesture detection.
- **Specifics**: Using MediaPipe Hands to recognize specific gestures like the "OK" sign from a webcam feed.

### 3. Object Detection
- **Goal**: General object detection and tracking.
- **Specifics**: Animal detection, human face detection with YOLO, and multi-object tracking using Ultralytics.

### 4. Real-Time MultiVision Objects and Emotions Detection
- **Goal**: Develop a multitask AI system for real-time video processing.
- **Phases**:
  - **Phase 1**: Facial emotion recognition using YOLO models trained on AffectNet.
  - **Phase 2**: Multitask integration of object detection and emotion recognition.
  - **Phase 3**: Optimization for real-time performance and deployment.
